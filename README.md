# Hub Settings

Одно окно с настройками всех приложений набора ([Island](../island), [Sidebar](../sidebar) и следующих). Сами приложения своих окон настроек не имеют. Выглядит как Системные настройки macOS.

## Как работает

- Окно как Системные настройки: слева список (сверху поиск, потом «Основные», ниже модули), справа экран модуля. Окно помнит размер и последний открытый модуль.
- Поиск ищет по всем настройкам всех модулей: выбрали результат - открывается модуль, строка прокручивается в центр и подсвечивается.
- Экран модуля: шапка (значок, название, строка описания), переключатель «Включено» (запускает или закрывает приложение модуля; у выключенного настройки приглушены), живое превью, секции с пояснениями, внизу «Сбросить настройки модуля…» с подтверждением.
- Контролы нативные: переключатели, выбор (сегменты или меню), ползунок со значением справа, образцы цвета, поле сочетания клавиш, список с перетаскиванием.
- Всё применяется сразу, без «Сохранить»: хаб пишет `settings.json` приложения, приложение подхватывает изменение на лету. ⌘Z отменяет, ⇧⌘Z повторяет.
- **Живое превью** - настоящий интерфейс острова или панели (`IslandUI`, `SidebarUI`). Наведите курсор и тяните за края; вкладки и виджеты перетаскиваются, убранные лежат в лотке под превью.
- Только системные шрифты и цвета: светлая и тёмная тема и акцентный цвет системы работают сами. Все размеры и цвета - в `DesignTokens.swift`.

## Как добавить модуль

- **Приложение с настройками.** Опубликуйте схему (`SuiteSchema(...).publish(defaults:)`, см. ниже) - модуль сам появится в списке, в поиске и на «Основных». Bundle id должен быть `com.roman.<app>`, тогда заработает «Включено».
- **По желанию - оформление.** В `ModuleCatalog` (`SchemaModule.swift`) можно задать цвет плитки, строку описания, порядок секций, подписи простыми словами и формат значений. Ключи настроек это не меняет. Без записи модуль получит цвет по имени и подписи из схемы.
- **Приложение, которое хранит настройки в своих UserDefaults** (Flow, Awake): опишите его схему в `ExternalSettings.swift` - хаб пишет прямо в его UserDefaults и присылает уведомление `com.roman.suite.<app>.settings`, приложение перечитывает настройки на лету.
- Установленное приложение набора без всякой схемы появится само - его можно только включать и выключать.
- **Модуль без схемы** (например, настройки самого хаба): реализуйте протокол `SettingsModule` (`SettingsModule.swift`) и добавьте его в `ModuleRegistry.modules`.

## Откуда хаб знает про настройки

Каждое приложение при запуске кладёт в `~/Library/Application Support/RomanSuite/<app>/schema.json` описание своих настроек (`SuiteSchema` из [SuiteKit](../SuiteKit)): группы, подписи, тип контрола, пределы и значения по умолчанию. Экран настроек хаб строит только по схеме: новое приложение появится в списке после первого запуска. Живое превью хаб умеет показывать для приложений, чей интерфейс вынесен в библиотеку (сейчас Island и Sidebar).

Поле `preview` в схеме говорит, какое превью рисовать (`island`, `sidebar`); у вариантов списка есть значок `symbol`.

Типы полей: переключатель, число (ползунок), выбор из вариантов, упорядоченный список (что включено и в каком порядке), цвет и горячая клавиша.

## Установка

Нужны только Command Line Tools (`xcode-select --install`) и папки `SuiteKit`, `island` и `sidebar` рядом с папкой проекта.

```bash
./build.sh install
```

`./build.sh` собирает `build/Hub Settings.app`, `./build.sh run` собирает и запускает отсюда.
