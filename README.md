# Hub Settings

Одно окно с настройками всех приложений набора ([Island](../island), [Sidebar](../sidebar) и следующих). Сами приложения своих окон настроек не имеют. Выглядит как Системные настройки: системные цвета Apple, полупрозрачная колонка, карточки групп.

## Как работает

- Раскладка как в графическом редакторе: слева приложения, в центре холст с живым превью (не уезжает при прокрутке), справа инспектор с настройками.
- Инспектор: сворачиваемые секции, поиск по настройкам, у числа ползунок и поле для точного значения, за название числа можно тянуть влево-вправо. У изменённой настройки синяя точка: нажми, чтобы вернуть стандартное значение. ⌘Z отменяет, ⇧⌘Z повторяет.
- Всё применяется сразу, без «Сохранить»: хаб пишет `settings.json` приложения, а приложение подхватывает изменение на лету. Ползунки двигают приложение прямо во время перетаскивания.
- **Живое превью.** Над настройками стоит не рисунок, а настоящий интерфейс острова или панели (библиотеки `IslandUI` и `SidebarUI`) с настоящими данными: полка, буфер, лимиты, музыка, таймер. Поэтому превью неотличимо от приложения.
- **Ручки, как в графическом редакторе.** Наведи курсор на превью: у острова тянутся бока (ширина), низ (высота) и кружок в углу (скругление), у панели левый край (ширина) и ручка со стрелками (положение по высоте). Под фигурой виден размер. Всё сразу меняется и в приложении.
- Вкладки острова и виджеты панели в превью перетаскиваются, чтобы переставить, и вытаскиваются наружу, чтобы убрать. Убранные лежат в лотке под превью и возвращаются по нажатию.
- Строки в списках тоже перетаскиваются, выключатель справа убирает и возвращает пункт.
- «Сбросить» возвращает настройки приложения к стандартным.
- Закрыли окно, и хаб выходит: в фоне ему делать нечего.

## Откуда хаб знает про настройки

Каждое приложение при запуске кладёт в `~/Library/Application Support/RomanSuite/<app>/schema.json` описание своих настроек (`SuiteSchema` из [SuiteKit](../SuiteKit)): группы, подписи, тип контрола, пределы и значения по умолчанию. Экран настроек хаб строит только по схеме: новое приложение появится в списке после первого запуска. Живое превью хаб умеет показывать для приложений, чей интерфейс вынесен в библиотеку (сейчас Island и Sidebar).

Поле `preview` в схеме говорит, какое превью рисовать (`island`, `sidebar`); у вариантов списка есть значок `symbol`.

Типы полей: переключатель, число (ползунок), выбор из вариантов, упорядоченный список (что включено и в каком порядке), цвет и горячая клавиша.

## Установка

Нужны только Command Line Tools (`xcode-select --install`) и папки `SuiteKit`, `island` и `sidebar` рядом с папкой проекта.

```bash
./build.sh install
```

`./build.sh` собирает `build/Hub Settings.app`, `./build.sh run` собирает и запускает отсюда.
