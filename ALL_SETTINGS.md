# ALL_SETTINGS — полный список настроек набора Mac-приложений

Составлен 2026-10-05 чтением кода и опубликованных схем (`~/Library/Application Support/RomanSuite/<app>/schema.json`, `settings.json`, `ModuleCatalog` хаба, `ExternalSettings.swift`, токены дизайна острова и т.д.). Код приложений не менялся.

## Легенда пометок

- **[есть]** — настройка уже существует. Указано: ключ в файле настроек, тип, диапазон/варианты, значение по умолчанию (из схемы), видимость в хабе: **видно** (на странице), **для задротов** (спрятана в свёрнутую секцию «Тонкая настройка», см. `advanced`), **скрыто** (`hidden`, переключается прямо в приложении). Пометка «не в схеме» — ключ или состояние есть в приложении, но хаб его не показывает.
- **[в коде]** — число, цвет, тайминг или поведение зашито в коде и не вынесено в настройки; указано, где лежит (файл/символ).
- **[идея]** — разумная настройка, которой нет вообще.
- Формат ключей Island: `moduleOptions.<id>.<ключ>` = параметр вкладки или функции `<id>`.
- Значения по умолчанию взяты из `schema.json` приложения (у пользователя в `settings.json` могут стоять свои).
- Один пункт — одна строка списка; некоторые строки объединяют несколько родственных ключей (например размеры вкладок), поэтому число пунктов «есть» меньше числа ключей (в схеме Island 339 значений по умолчанию).

## Hub Settings — сам хаб

Окно настроек всего набора (apps/hub-settings, bundle `com.roman.hub-settings`). Свои настройки хранит в UserDefaults хаба и в `HubModel` (последний открытый модуль, позиция окна). Настроек самого хаба в UI почти нет: только список модулей и папка файлов.

### Основные (первая вкладка хаба)

- [есть] `general.module.<app>` — переключатель «включён» у каждого установленного приложения набора (запуск/закрытие процесса); тип: вкл/выкл; видно. Список строится из установленных приложений (`AppMonitor`).
- [есть] «Папка настроек» — кнопка «Показать в Finder» (`~/Library/Application Support/RomanSuite`); видно.
- [есть] `showAdvanced` (UserDefaults хаба, `HubPreferences.showAdvanced`) — показывать секции «Тонкая настройка»; вкл/выкл; по умолч. выкл; переключается в интерфейсе хаба (не в файле набора).
- [есть] `page.<module.id>` (UserDefaults хаба) — запоминает последнюю открытую подстраницу модуля; не настройка, но состояние.
- [есть] `HubModel.selection` — последний выбранный модуль; состояние.
- [в коде] Заголовок окна «Hub Settings», id окна `main` (HubApp.swift).
- [в коде] Закрыл окно — приложение выходит (`applicationShouldTerminateAfterLastWindowClosed = true`, HubApp.swift).
- [в коде] Размер окна по умолчанию 960×680, минимум 760×480, имя автосохранения `HubSettingsWindow` (DesignTokens.swift `WindowMetrics`).
- [в коде] Окно всегда тёмное: `window.appearance = darkAqua`, прозрачный фон, скрытый заголовок (HubApp.swift).
- [в коде] Ширина списка модулей 230 pt (`ScreenMetrics.listWidth`), максимальная ширина формы 680 pt (`formMaxWidth`).
- [в коде] Строка поиска: ширина 460, высота 30, радиус 8 (`TopBarMetrics`); горячая клавиша ⌘F; отступ от светофоров 80.

- [в коде] Горячие клавиши: ⌘Z / ⇧⌘Z — отмена и повтор изменений настроек (HubApp.swift), пружина `Motion.spring`.
- [в коде] Палитра цветов плиток модулей (системные: gray, blue, indigo, purple, pink, red, orange, yellow, green, mint, teal, cyan, brown) и запасной цвет «по имени приложения» (`TileColor.stable`).

## Общие настройки всего набора

Сейчас общего окна «для всех» нет: общие вещи живут в `SuiteKit` (шина, пути, схема, энергия) и в Island (профили, клавиши). Ниже — то, что имело бы смысл вынести на общий уровень.

### Файлы и пути набора

- [в коде] Корень данных `~/Library/Application Support/RomanSuite` (`SuitePaths.root`, SuiteKit); у каждого приложения своя папка `<app>/` с `schema.json` и `settings.json`.
- [в коде] Общие каталоги: `clipboard/` (история и картинки), `claude/` (limits.json, statusline.json), `claude-code/` (hook.sh, sessions), `mesh/`, `yandex/`, `sidebar/pins.json`, `island/*.json` (media, timers, weather, prices…).
- [в коде] Журналы: `~/Library/Logs/FlowLocal.log`; записи Flow в `~/Library/Application Support/FlowLocal/Recordings`.
- [идея] Папка данных набора: переносимая (выбрать другой диск), очистка кэша (обложки, погода, цены, тексты песен).
- [идея] Лимит размера кэша набора и автоочистка старше N дней.
- [идея] Расположение журналов, уровень подробности, ротация (размер, число файлов).
- [идея] Шифрование чувствительных файлов (токены МЭШ/Яндекс/Spotify) в Keychain вместо файлов.

### Связь между приложениями (SuiteBus, распределённые уведомления)

- [в коде] Шина `SuiteBus` (SuiteKit/SuiteBus.swift): распределённые уведомления вида `com.roman.suite.<app>.settings/.changed/.state` — имена зашиты.
- [в коде] Island принимает команды от приложений набора (`moduleOptions.urlControl.suiteBus`, есть в схеме).
- [идея] Включить/выключить обмен между приложениями целиком; «изолированный режим».
- [идея] Список разрешённых отправителей команд (по bundle ID).
- [идея] Журнал команд шины (последние 100) и отладочный вывод.
- [идея] Частота обновления общих данных (статус Claude, лимиты, медиа) для всех приложений одной настройкой.

### Общий внешний вид

- [в коде] Все приложения набора рисуют остров/панель в тёмной теме и белым текстом разной прозрачности (острова: `IslandColor`, Sidebar: белый 12–85%).
- [в коде] Акцентный цвет в каждом приложении свой: Island `accent`, Hub системный, Flow `Theme.swift`.
- [идея] Единый акцентный цвет набора (один выбор для Island, Sidebar, Shelf, Flow, Horizon).
- [идея] Единая тема: тёмная / светлая / авто на всё.
- [идея] Единая палитра смысловых цветов (норма/предупреждение/критично) и пороги (Island `claude.warnAt/criticalAt`, Sidebar `limitWarn/limitDanger`, `lowBattery` есть в обоих — общие пороги).
- [идея] Единая скорость анимаций (`animationSpeed`) и уменьшение движения по системной настройке.
- [идея] Единый стиль стекла (Liquid Glass/размытие/сплошной) и его параметры.
- [идея] Единые скругления (радиус для острова, панели, окон Shelf/Flow).
- [идея] Единый шрифт (SF Pro / SF Rounded / моно) и множитель размера.
- [идея] Единые иконки: SF Symbols заливка / контур; толщина.

## Island — остров в чёлке

Приложение apps/island (`com.roman.island`): окно в верхней части экрана, три состояния — спрятан (hidden), свёрнут (peek, «уши» по бокам чёлки) и раскрыт (open, вкладки-модули). Настройки: `RomanSuite/island/settings.json`, схема публикуется в `schema.json`. Параметры вкладок и функций — ключи `moduleOptions.<id>.<ключ>`. В схеме 339 значений по умолчанию; видимость в хабе задаёт `ModuleCatalog.island` (hidden/advanced).
Часть ключей лежит в `settings.json`, но в схему хаба не опубликована (openWidth, openHeight, openCorner, tabOrder, timerSound, shelfTilt, contentPadding, profile, profileChosen, musicEnabled в части сборок) — помечены «не в схеме».

## Flow (FlowLocal) — диктовка

Приложение apps/flow-local/mac (`com.flowlocal.mac`): зажать клавишу, говорить, текст вставится. Распознавание: локальный GigaAM через Python-сервер. Настройки живут в UserDefaults приложения, хаб правит эти же ключи и шлёт распределённое уведомление `com.roman.suite.flow.settings`; приложение отвечает `…changed`. Схема описана в `ExternalSettings.swift` (в `schema.json` Flow не публикуется). Окна настроек во Flow нет — всё в хабе. Видимость: «для задротов» = `ModuleCatalog.flow.advanced`.

- [в коде] Esc во время записи — отмена (хоткей id 2, регистрируется только на время записи).
- [в коде] Удержание короче 0.35 с трактуется как «нажатие», длиннее — «удержание» (`Controller`: `Date().timeIntervalSince(t) > 0.35`).

- [идея] Третье сочетание: «отменить последнюю диктовку», «вставить последнюю диктовку заново», «открыть окно Flow».

## Wow — камера с 3D-масками

Приложение apps/wow-app (Swift Package, сборка `./build.sh`): камера с 3D-масками для детей; маски — кнопками, клавишами или голосом (правый ⌥, GigaAM из окружения Flow); жесты рук, реакции, режимы вида, запись фото и видео. Постоянных настроек нет: `AppOnlyModule` в хабе, схемы нет, всё состояние в памяти (`AppModel`). Всё ниже — потенциальные настройки.

### Что есть в приложении (всё зашито в коде)

- [в коде] Режимы вида (`Look`): Обычный, Ч/Б, Комикс, Тепловизор, Поп-арт (Model.swift).
- [в коде] Команды (Commands.swift): выбор маски/вида, сброс, следующая, случайная, фото, видео, стоп, «описать» (комментатор).
- [в коде] Жесты рук (HandTracker): большой палец вверх/вниз, мир (peace), рок, ок, кулак, ладонь, щипок; реакции: thumbsUp, fireworks, thumbsDown, balloons, confetti, hearts, rock; переключение маски вперёд/назад, фото, запись видео.
- [в коде] Видимые реакции: спрайты, искры, конфетти, дождь, молнии (Reactions.swift); частицы, скорости и времена жизни зашиты.
- [в коде] Захват камеры: пресеты по очереди `.hd1920x1080`, `.hd1280x720`, `.high` (Pipeline.swift, берётся первый поддерживаемый).
- [в коде] Запись видео: средний битрейт 14 000 000 бит/с (VideoRecorder.swift).
- [в коде] Уровни голоса: 28 столбиков (`levels`).
- [в коде] Комментатор: Ollama + модель, видящая картинки (ошибки «не запущена Ollama», «нет модели с картинками») (Commentator.swift).
- [в коде] Маски: библиотека `MaskLibrary`, `Spec(...)` в Masks.swift: название, эмодзи, раздел, слова для голоса, посадка (размер/сдвиг); маски — USDZ из Resources/Masks.
- [в коде] Эффекты лица: FaceEffects, FaceMesh, FaceTracker (Vision); VoiceBackend: SpeechBackend (starting/ready/off).
